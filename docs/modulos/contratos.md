# Módulo de contratos

El módulo de contratos permite generar, consultar y administrar contratos de arrendamiento dentro del sistema RentifyV2.

## Funcionalidades relacionadas

- Generación automática de contratos.
- Validación de información necesaria para el contrato.
- Guardado del contrato en el sistema.
- Consulta de contratos generados.
- Generación de archivo PDF del contrato.
- Registro del estado del contrato.
- Firma del contrato por las partes involucradas.

## Clases relacionadas

Algunas clases relacionadas con este módulo son:

- ContratoFormController
- ContratosController
- ContratoTabla
- PdfContratoUtil

## Importancia dentro del sistema

Este módulo es importante porque formaliza el proceso de arrendamiento entre el arrendador y el arrendatario. Además, permite mantener evidencia documental de los acuerdos realizados dentro de la plataforma.
